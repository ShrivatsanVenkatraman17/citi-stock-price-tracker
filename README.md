# DIA Stock Price Tracker

A Java application developed as part of Citi's
Technology Software Development Simulation.

## Features
- Retrieves DIA stock prices using the Twelve Data API.
- Captures timestamps for each observation.
- Stores price observations in a Java queue.
- Repeats data collection every 15 seconds.

## Technologies
- Java
- Python
- Twelve Data API
- Google Colab

## Purpose
This project demonstrates Java programming, API integration,
and basic financial data collection.
